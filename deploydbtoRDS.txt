# 10. Important `server.port`

Your Spring Boot application was using:

```properties
server.port=8080
```

So:

```text
Spring Boot
    ↓
8080
```

But **Postman should NOT call the RDS endpoint on port 8080**.

This was one of the issues we identified.

### Wrong

```text
http://jobportal-db.cf8oqceysoy9.ap-south-1.rds.amazonaws.com:8080/...
```

### Correct concept

Postman calls the **Elastic Beanstalk application**:

```text
http://<elastic-beanstalk-url>:8080/...
```

or the EB/load-balancer URL depending on your configuration.

RDS is only the database:

```text
jobportal-db.cf8oqceysoy9.ap-south-1.rds.amazonaws.com:5432
```
